# Рекомендовані anchor-тексти для внутрішньої перелінковки

## Правило використання

- Для кожної цільової сторінки тримайте 1 основний anchor, 2-3 варіації та 1 брендований anchor.
- Не ставте один і той самий точний anchor 5-10 разів підряд з різних сторінок.
- Комерційні запити ведіть на категорії й товарні сторінки, інформаційні запити лишайте для статей.
